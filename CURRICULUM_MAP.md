## 5. Skill strands (text/task types by level)

- **Listening:** words/phrases → slow exchanges → announcements → clear
  standard speech → extended/idiomatic speech → lectures/implicature →
  IELTS 4-part tactics.
- **Speaking:** words/chunks → sentences → 1–2 min turns → 2–3 min reasons →
  sustained discussion → seminar/presentation → IELTS 3-part criteria.
- **Reading:** words/lines → notices/menus → emails/stories → news/notices →
  argument/reports → dense academic → IELTS 10+ question types.
- **Writing:** copy/words → 40–80w → 80–120w → 120–180w → 180–250w →
  thesis essays/data → IELTS T1+T2 criteria.
- **Pronunciation:** sounds/stress → endings → weak forms → thought groups →
  attitude intonation → natural delivery → clarity under pressure.

## 6. Review and assessment spine

- In-lesson: active recall (§15) + Review Plan (§19) every lesson.
- Spaced schedule: next lesson → +1d → +3d → +7d → +21d → +60d (adaptive;
  failure resets to +1d with an error code).
- Unit tests: 98 (final lesson of each unit). Module checkpoints: 46.
- Level tests: 6. Cumulative: CUM-A2, CUM-B2, CUM-C1.
- IELTS: diagnostic + 18 checkpoints + 2 full mocks + readiness review.
- Full framework: `ASSESSMENT_REGISTER.md`.
