# ASSESSMENT_REGISTER — Framework and Register

## 1. Framework

**Types.** diagnostic (DIAG-00 placement; IE diagnostic) · lesson checks
(embedded in every lesson, template §17) · unit tests (98) · module
checkpoints (46) · level tests (6) · cumulative tests (3) · IELTS mocks (2)
· readiness review (1).

**ID scheme.** Lesson checks: `{lesson_id}-QZ` (embedded, not separate files).
Unit tests: `{LEVEL}-U{uu}-T`. Module checkpoints: `{LEVEL}-M{m}-C`. Level
tests: `{LEVEL}-LT`. Cumulative: `CUM-A2`, `CUM-B2`, `CUM-C1`. IELTS:
`IE-DIAG`, `IE-MOCK-1`, `IE-MOCK-2`, `IE-READY`.

**Blueprints.** Every separate assessment follows
`templates/ASSESSMENT_TEMPLATE.md`: 100-point blueprint across skills,
exact student instructions, key + scoring, error codes (Deliverable C §C.8),
interpretation bands, and a remediation map.

**Interpretation bands (unit tests and above).**

| Score | Meaning | Action |
|---|---|---|
| 85–100 | Strong | Continue; normal review |
| 70–84 | Adequate | Continue + targeted repair tasks |
| 50–69 | Weak | Remediation plan first; then continue |
| 0–49 | Not ready | Re-study; retake a parallel form |

**Progression rule.** Advance past a unit with ≥70% (after any allowed
retake). Advance past a level per Deliverable A gates. Retakes require a
parallel form — never the same paper twice.

**Mastery contribution.** Assessment success feeds item mastery (Deliverable C
§C.4–C.5): a correct dedicated item moves vocab `used→assessed`; grammar
`practiced→assessed` needs test + spontaneous-use evidence.

**Speaking/writing honesty.** Scores require recorded/permanent evidence
(audio file, written text) against a rubric. Without evidence, record
`not-assessed` — never invent a score.

**Remediation rule.** Any error code appearing ≥3 times in a window triggers
repair tasks from the assessment's remediation map before new material. The
repair + retake + outcome are logged in §3.
