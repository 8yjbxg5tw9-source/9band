# Deliverable B — Detailed Breakdown: Modules, Units, Objectives, Dependencies, Checkpoints

Companion to Deliverable A (level targets) and `docs/STRUCTURE_TABLES.md`
(full ID listing). This document gives every module's units, one-line unit
objectives, grammar anchors (from `GRAMMAR_DATABASE.csv`), and the
assessment/dependency rules that bind the course together.

Conventions:

- Unit IDs: `{LEVEL}-M{m}-U{u}`; lessons append `-L{nn}`.
- Grammar anchors list topics *introduced* in the unit. Units marked
  **(lexical)** introduce no new grammar by design — they deepen vocabulary,
  skills, and fluency. This is deliberate load-balancing, not a gap.
- Every unit's final lesson is a review + unit test (`{LEVEL}-U{u:02d}-T`).

## B.8 Dependencies and gating

1. **Linear lesson chain.** Each lesson lists its predecessor as prerequisite
   (`LESSON_INDEX.csv`). A learner may not skip ahead past an unpassed unit
   test without a recorded remediation decision.
2. **Level gates.** The first lesson of each level is gated by the previous
   level test (A0-LT → A1 … C1-LT → IE). Direct entry at any level is allowed
   only via the diagnostic placement assessment (DIAG-00).
3. **Grammar dependency chains** (from `GRAMMAR_DATABASE.csv`, selected long
   chains the schedule must respect):
   - BE chain: G003 → G004 → G008 → G009 → G010 → (G029 past BE) → G043/G044
   - Present chain: G014 → G015 → G016 → G017 → G018 → G041 → G042
   - Past chain: G030 → G031 → G032 → G044 → G063 → (G068 reported)
   - Future chain: G035 → G045 → G046 → G077 → G078
   - Conditional chain: G057 → G058 → G065 → G081 → G082
   - Passive chain: G066 → G067 → G084 → G085
   - Perfect chain: G051 → G052 → G053 → G061 → G062
   - Clause chain: G070 → G071 → G087 → G089; cohesion: G080 → G094 → G100
   No lesson may use a structure whose chain prerequisites are unintroduced,
   except as explicitly glossed incidental language (Deliverable D, §D.3).
4. **Vocabulary dependency.** Lessons use words with status ≥ introduced; new
   words respect per-lesson maxima (A0–A1: 8; A2: 10; B1: 12; B2–C1/IE: 15).
5. **Skill spirals.** Each skill's text/task types recur with rising difficulty
   (see Deliverable A, §A.3). A task type first appears in guided form, then
   timed/independent form at least one unit later.
