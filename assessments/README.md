# Assessments

One file per separate assessment: `assessments/{assessment_id}.md`, authored
from `templates/ASSESSMENT_TEMPLATE.md`. (Lesson checks are embedded in the
lesson files, not stored here.)

ID families: `{LEVEL}-U{uu}-T` (unit tests) · `{LEVEL}-M{m}-C` (module
checkpoints) · `{LEVEL}-LT` (level tests) · `CUM-A2/B2/C1` (cumulative) ·
`IE-DIAG`, `IE-MOCK-1`, `IE-MOCK-2`, `IE-READY` (IELTS).

Rules:

1. Student-facing instructions inside each file are **English-only**.
2. Blueprint before items; keys verified by second-pass solving.
3. Status tracked in `ASSESSMENT_REGISTER.md`; sign-offs in `QUALITY_AUDIT.md`.
